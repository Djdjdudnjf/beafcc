# Replay — تحليل مبارياتك (نسخة بهوية جديدة + خلفية تجريبية)

موقع تحليل مباريات كرة القدم، مبني على نفس هيكل `r2w.yamsoft.dev` لكن:

- **اسم جديد:** Replay / RP بدل «Replay to Win».
- **هوية جديدة:** اللون الأساسي صار **أزرق سماوي** بدل الأخضر — في الواجهة كلها، اللوقو، الأيقونات، وصورة المشاركة.
- **خلفية تجريبية (Demo):** كل شي يشتغل محليًا بدون سيرفر حقيقي.

## التشغيل

```bash
python3 -m http.server 8099
# افتح: http://localhost:8099
```
(لازم سيرفر محلي، فتح الملف مباشرة ما يكفي.)

## وش يشتغل في الوضع التجريبي

ملف `demo.js` يعترض كل طلبات `/api/*` ويرجّع بيانات واقعية تُحفظ في متصفحك (`localStorage`):

- **تسجيل الدخول / إنشاء حساب:** أي بريد وأي كلمة مرور تدخلك مباشرة.
- **تحليل مباراة:** ارفع مقطع فيديو → يطلع لك تقرير كامل (تقييم، لحظات حاسمة، أخطاء، نقاط قوة، تكتيك، تمارين، ومهمة واحدة). كل تقرير يتولّد بأرقام واسم فريق مختلف.
- **سجلّي:** تقاريرك تتحفظ وتقدر تفتحها من جديد.
- **قائمة المتصدرين، رحلتي، اسأل المدرّب، الأسعار والدفع:** كلها ترد ببيانات تجريبية (الدفع يفتح الاشتراك فورًا بدون بوابة حقيقية).
- **التقرير النموذجي** («شاهد تقريرًا كاملًا») يشتغل بدون حساب.

> ملاحظة: هذا تحليل **تجريبي** — ما فيه ذكاء اصطناعي حقيقي يشاهد الفيديو. التقرير مُولّد من قالب جاهز لعرض شكل المنتج وتجربته.

## أبرز الملفات

| الملف | الوظيفة |
|------|---------|
| `index.html` | الصفحة الرئيسية |
| `demo.js` | الخلفية التجريبية (اعتراض `/api/*`) |
| `app.css`, `app.js`, `replay.js` | التصميم والمنطق الأصلي |
| `logo.svg` + `icon-*.png`, `favicon.png`, `og.jpg` | الهوية الجديدة (مولّدة بالأزرق) |
| `fonts/` | خطوط Plex + علامة الموقع |
| `m/` | فيديوهات الخلفية والعروض |
| `terms/privacy/refund/contact.html` | الصفحات الفرعية |

## تبي توقف الوضع التجريبي؟

احذف سطر `<script src="demo.js?v=1"></script>` من `index.html`، ووجّه `/api/*` لسيرفرك الحقيقي.
