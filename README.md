# مرشد (Murshid) — منصة مساعدين أذكياء

موقع واحد فيه **ثلاثة مساعدين أذكياء**، تختار بينهم من الصفحة الرئيسية:

| المساعد | ماذا يفعل | ما لا يفعله |
|---|---|---|
| ⚕️ **المساعد الطبي** | يشرح المعلومات الصحية بلغة مبسطة ويوضّح متى تراجع الطبيب | لا يشخّص ولا يصف علاجاً |
| 👨‍🍳 **مساعد الطبخ** | يقترح وصفات من مكوناتك المتوفرة ويضبط المقادير حسب عدد الأشخاص | يسألك عن مكوناتك أولاً إن لم تذكرها |
| 📐 **مساعد الرياضيات** | يحل المسائل ويشرح **كل خطوة ولماذا** | لا يعطيك الجواب النهائي وحده |

كل مساعد **يرفض بأدب** أي سؤال خارج تخصصه ويوجهك للمساعد الصحيح.

## الخطوة ١: تثبيت Node.js

**ما هو Node.js؟** برنامج يجعل حاسوبك قادراً على تشغيل ملفات JavaScript (لغة البرمجة التي بُني بها هذا المشروع). بدونه لن يعمل شيء.

1. افتح المتصفح واذهب إلى: **https://nodejs.org**
2. سترى زرين كبيرين. اضغط الزر المكتوب عليه **LTS** (تعني: النسخة المستقرة الموصى بها).
3. سيُحمَّل ملف التثبيت. افتحه بعد انتهاء التحميل.
4. اضغط **Next → Next → Install** حتى ينتهي، ثم **Finish**.
   - إذا ظهر خيار اسمه `Add to PATH` تأكد أنه **مُفعَّل** (يكون مفعلاً افتراضياً).
5. **أعد تشغيل الحاسوب** (خطوة مهمة كثيرون ينسونها، وبدونها قد لا يتعرف الحاسوب على الأمر).

## الخطوة ٢: فتح "الطرفية" (Terminal)

**ما هي الطرفية؟** نافذة سوداء (أو بيضاء) تكتب فيها **أوامر نصية** للحاسوب بدل الضغط بالفأرة. كل ما ستفعله هو نسخ الأوامر من هنا ولصقها هناك ثم الضغط على Enter.

### على ويندوز (Windows)
1. اضغط زر **Windows** في لوحة المفاتيح.
2. اكتب: `powershell`
3. اضغط **Enter**. ستُفتح نافذة زرقاء أو سوداء — هذه هي الطرفية.

### على ماك (Mac)
1. اضغط **Command (⌘) + مسافة** معاً.
2. اكتب: `terminal`
3. اضغط **Enter**.

### تأكد أن Node.js ثُبِّت بنجاح
انسخ هذا السطر والصقه في الطرفية ثم اضغط Enter:

```
node --version
```

**النتيجة المتوقعة:** رقم مثل `v22.14.0`.
- ✅ إذا ظهر رقم → ممتاز، أكمل.
- ❌ إذا ظهر `command not found` أو `is not recognized` → لم يُثبَّت Node.js بشكل صحيح. أعد الخطوة ١ وتأكد من إعادة تشغيل الحاسوب.

> 💡 **كيف تلصق في الطرفية؟**
> - ويندوز: زر الفأرة الأيمن، أو `Ctrl + V`
> - ماك: `Command (⌘) + V`

## الخطوة ٣: الدخول إلى مجلد المشروع

**المقصود:** إخبار الطرفية "اعملي داخل هذا المجلد".

الأمر المستخدم هو `cd` (اختصار لـ **c**hange **d**irectory أي "غيّر المجلد").

1. افتح مجلد المشروع بمستكشف الملفات العادي.
2. انسخ **مسار المجلد** الكامل:
   - **ويندوز:** اضغط على شريط العنوان في أعلى نافذة المجلد، سيتحول لنص مثل `C:\Users\Ahmed\Downloads\murshid` — انسخه.
   - **ماك:** اضغط بزر الفأرة الأيمن على المجلد → اضغط مفتاح `Option` → اختر `Copy … as Pathname`.
3. في الطرفية اكتب `cd` ثم **مسافة** ثم الصق المسار، مثال:

```
cd C:\Users\Ahmed\Downloads\murshid
```

4. اضغط Enter. للتأكد أنك في المكان الصحيح اكتب:

```
dir
```
(على ماك ولينكس استخدم `ls` بدلاً منها)

**النتيجة المتوقعة:** ترى في القائمة المجلدين `backend` و `frontend`. إذا لم ترهما فأنت في المجلد الخطأ — أعد الخطوة.

## الخطوة ٥: الحصول على مفتاح Claude API ووضعه في مكانه

**ما هو مفتاح API؟** كلمة سر طويلة تثبت لخوادم Claude أنك أنت، وتُحسب عليها تكلفة الاستخدام. **لا تشاركها مع أحد ولا تنشرها في أي مكان.**

### أ) الحصول على المفتاح

1. اذهب إلى: **https://console.anthropic.com**
2. سجّل حساباً جديداً (أو ادخل بحسابك إن كان لديك).
3. من القائمة الجانبية اختر **Settings** ثم **API Keys**.
   - أو اذهب مباشرة إلى: https://console.anthropic.com/settings/keys
4. اضغط زر **Create Key**.
5. اكتب أي اسم للمفتاح (مثلاً: `murshid`) ثم اضغط **Create**.
6. سيظهر لك المفتاح، ويبدأ بـ `sk-ant-`. اضغط زر النسخ 📋.

> 🔴 **مهم جداً:** المفتاح يظهر **مرة واحدة فقط**. إن أغلقت النافذة قبل نسخه فستحتاج إنشاء مفتاح جديد.

> 💳 **ملاحظة عن الرصيد:** استخدام الـ API مدفوع بالاستهلاك. تحتاج شحن رصيد من صفحة **Billing** في نفس الموقع (عادة ٥ دولار تكفي لتجارب كثيرة). إن ظهرت لك رسالة `credit balance is too low` فالسبب أن رصيدك انتهى.

### ب) وضع المفتاح في المشروع (بالضبط)

1. افتح مجلد المشروع، ثم افتح مجلد **`backend`**.
2. ستجد ملفاً اسمه **`.env.example`** — انسخه والصقه في **نفس المجلد**.
3. غيّر اسم النسخة إلى **`.env`** بالضبط:
   - ✅ الاسم الصحيح: `.env` (نقطة ثم كلمة env، **بدون** أي امتداد آخر)
   - ❌ خطأ شائع: `env` أو `.env.txt` أو `.env.example`
4. افتح ملف `.env` بأي محرر نصوص:
   - **ويندوز:** اضغط بزر الفأرة الأيمن → `Open with` → **Notepad**
   - **ماك:** اضغط بزر الفأرة الأيمن → `Open With` → **TextEdit**
5. ابحث عن السطر:
   ```
   ANTHROPIC_API_KEY=ضع_مفتاحك_هنا
   ```
6. احذف `ضع_مفتاحك_هنا` والصق مفتاحك مكانها، ليصبح السطر هكذا:
   ```
   ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxxxxxxxxxxxxxx
   ```
   > ⚠️ **بدون** مسافات حول علامة `=` و**بدون** علامات تنصيص `" "`.
7. احفظ الملف (`Ctrl + S` على ويندوز، `Command + S` على ماك) وأغلقه.

> 🙈 **لا يظهر لك ملف `.env.example`؟** الملفات التي تبدأ بنقطة تكون مخفية أحياناً:
> - **ويندوز:** في نافذة المجلد اضغط `View` ← فعّل `Hidden items`
> - **ماك:** اضغط `Command + Shift + .` (نقطة)

# 🔧 حل المشاكل الشائعة

| ما تراه | السبب | الحل |
|---|---|---|
| `command not found: node` | Node.js غير مثبت | أعد الخطوة ١ وأعد تشغيل الحاسوب |
| `command not found: npm` | نفس السبب أعلاه | نفس الحل |
| `Cannot find module 'express'` | لم تنفّذ `npm install` | ادخل مجلد `backend` ونفّذ `npm install` |
| `ENOENT: no such file or directory` بعد `cd` | المسار خطأ | تأكد أنك في المجلد الذي يحتوي `backend` و `frontend` |
| `المنفذ 3001 مشغول` | الخادم يعمل في نافذة أخرى | أغلق النافذة الأخرى، أو غيّر `PORT` في `.env` |
| `Port 5173 is in use` | الواجهة تعمل مسبقاً | Vite سيختار منفذاً آخر تلقائياً — استخدم الرابط الذي يظهر |
| **في الموقع:** "مفتاح Claude API غير صحيح" | المفتاح خطأ أو ناقص | راجع الخطوة ٥ — تأكد أن الاسم `.env` وأن المفتاح يبدأ بـ `sk-ant-` |
| **في الموقع:** "تعذّر الاتصال بالخادم" | نافذة الخادم مغلقة | ارجع للخطوة ٦ وشغّل الخادم |
| `credit balance is too low` | رصيد حسابك انتهى | اشحن رصيداً من https://console.anthropic.com/settings/billing |
| `تم إرسال طلبات كثيرة` | أرسلت رسائل بسرعة كبيرة | انتظر دقيقة وأعد المحاولة |
| الصفحة بيضاء فارغة | الواجهة لم تعمل | تأكد أن `npm run dev` يعمل، وجرّب تحديث الصفحة بـ `Ctrl+Shift+R` |

# ⚙️ تخصيص المشروع

## تعديل شخصية أحد المساعدين
افتح `backend/src/lib/prompts.js` وعدّل النص الخاص بالمساعد المطلوب.
بعد أي تعديل: أوقف الخادم بـ `Ctrl + C` وشغّله مجدداً بـ `npm start`.

## تغيير الإعدادات (ملف `backend/.env`)

| الإعداد | معناه | القيمة الافتراضية |
|---|---|---|
| `ANTHROPIC_MODEL` | موديل Claude المستخدم | `claude-opus-5` |
| `ANTHROPIC_EFFORT` | عمق التفكير: `low` أسرع وأرخص، `max` أعمق وأغلى | `high` |
| `MAX_TOKENS` | أقصى طول للرد الواحد | `8000` |
| `HISTORY_LIMIT` | كم رسالة سابقة يتذكرها المساعد | `30` |
| `PORT` | منفذ الخادم | `3001` |

> 💡 **لتقليل التكلفة:** غيّر `ANTHROPIC_EFFORT` إلى `medium` أو `low`.

## تغيير الألوان
افتح `frontend/src/styles/theme.css` وعدّل متغيرات الألوان في أعلى الملف.
التعديل يظهر في المتصفح **فوراً** بدون إعادة تشغيل.
