# Replay to Win — نسخة طبق الأصل

نسخة ثابتة (static) من موقع `r2w.yamsoft.dev`: نفس الواجهة، نفس التصميم، نفس النصوص والأصول (صور، فيديوهات، خطوط، SVG).

الواجهة كاملة وتشتغل محليًا. أي شي يحتاج سيرفر الموقع الأصلي (تسجيل الدخول، الرفع، الدفع، توليد التقرير الحقيقي) ما راح يشتغل، لأن هذي خدمة خلفية مو جزء من ملفات الصفحة.

## التشغيل

لازم سيرفر محلي (فتح `index.html` مباشرة ما يكفي بسبب الـ service worker وطلبات الملفات):

```bash
python3 -m http.server 8099
# افتح: http://localhost:8099
```

## الملفات

- `index.html` — الصفحة الرئيسية.
- `app.css`, `app.js`, `replay.js` — التصميم والمنطق.
- `sw.js`, `manifest.webmanifest` — إعداد PWA.
- `fonts/` — خطوط Plex وعلامة الموقع.
- `m/` — فيديوهات الخلفية والعروض.
- `terms.html`, `privacy.html`, `refund.html`, `contact.html` — الصفحات الفرعية.
- باقي الصور والأيقونات في الجذر.
