# الفُتوح — ٥٧ معركة

لعبة معارك تاريخية تعمل في المتصفح مباشرة — بلا تثبيت وبلا إنترنت بعد أول فتح.
**تقود جيشك بنفسك** في ٥٧ معركة حقيقية من تاريخ الفتوحات الإسلامية، من حروب الردة إلى وادي المَخازِن.

> كل معركة نصفُ دقيقة إلى دقيقتين — مصمّمة لوقت الفراغ.

---

## كيف ألعب؟

| الجهاز | التحكم |
|---|---|
| **آيباد / جوال** | إصبعٌ على **يسار** الشاشة = حركة القائد · إصبعٌ على **يمين** الشاشة = التصويب والضرب · زرّا **الاندفاع** و**الراية** أسفل اليمين |
| **حاسوب** | `WASD` أو الأسهم · الفأرة للتصويب (اضغط للضرب) · `مسافة` اندفاع · `Shift` الراية · `Esc` إيقاف |

- يظهر لك **مقبضٌ شبح** على يسار الشاشة يدلّك على مكان الإبهام — ضع إصبعك واسحب.
- إن لم تُصوّب بنفسك يضرب قائدك **أقرب عدوٍّ تلقائياً** (يمكن إطفاؤه من الإعدادات).
- **الراية** (الضربة القاضية): تشفي جيشك كله وتضاعف قوته عشر ثوانٍ وتُذهِل من حولك.
- تنتصر بإفناء جيش الخصم وقائده. تنكسر إذا سقط قائدك أنت.

## بعد كل نصر تختار واحدة

| الغنيمة | ماذا تعطيك |
|---|---|
| 🪙 **الغنيمة** | ذهبٌ تشتري به تطويراتٍ دائمة من دار السِّلاح |
| ⚔️ **قوة السيف** | +٪ ضرراً **لك ولجيشك** طوال الحملة |
| 🛡️ **عدد الجيش** | جنودٌ إضافيون ينضمّون إلى رايتك في كل معركة |

## ماذا في اللعبة؟

- **٥٧ معركة حقيقية** في ٩ فصول: حروب الردة ← العراق ← الشام ← فارس ← مصر وإفريقية ← المغرب والأندلس ← المشرق ← الصليبيون والمغول ← المماليك والعثمانيون.
- كل معركة باسمها وسنتها الهجرية والميلادية ومكانها وخصمها، ومعها **ملاحظة تاريخية صحيحة** — والنتيجة الحقيقية مذكورة كما وقعت، حتى الهزائم (الجِسر، تَهُودة، بلاط الشهداء، يوم الشِّعب).
- **١١ خصماً** لكلٍّ لونه وعتاده: الفرس، الروم، القوط، البربر، السند، الترك، الصليبيون، المغول، البرتغال…
- **٥ أنواع مقاتلين** للطرفين: سيّاف، رمّاح، حامل تُرس، رامٍ، فارس.
- **قائدٌ للخصم** في كل معركة يدخل بعد سقوط نصف جيشه، بخمسة أنماط هجوم وطَورِ غضب.
- **دار السِّلاح**: ١٠ تطويرات دائمة (بأس القائد، حدّ السيف، الاستنفار، دروع الجند، الرماة، الخيّالة…).
- **سِجل المعارك**: صفحةٌ تاريخية تُفتح مع كل نصر.
- موسيقى ومؤثرات **مولَّدة برمجياً** على المقامات العربية — بلا أي ملف صوتي، وكل الرسم متجهيّ إجرائي.

## التشغيل

### الأسهل
افتح `dist/futuh.html` في أي متصفح. يعمل حتى بلا إنترنت.

### على الآيباد كتطبيق
1. افتح الرابط في **سفاري**.
2. زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية**.
3. يفتح ملء الشاشة بلا شريط متصفح، ويعمل بلا إنترنت، ويحفظ تقدّمك.

### تشغيل محلي
```bash
cd game
npx serve .        # sw.js يحتاج http وليس file://
```

## للمطوّر

```
game/
├── index.html          الصفحة والشاشات
├── css/style.css       التنسيق (عربي RTL)
├── js/
│   ├── util.js         رياضيات، ألوان، أرقام عربية، عزل اتجاه النص
│   ├── save.js         الحفظ وتقدّم الحملة
│   ├── audio.js        WebAudio: مؤثرات وموسيقى على المقامات
│   ├── input.js        لمسٌ بإصبعين (مسار touch على iOS) + لوحة مفاتيح
│   ├── data.js         ٥٧ معركة، ٩ فصول، الخصوم، الجنود، المكافآت، دار السلاح
│   ├── fx.js           جسيمات، أرقام طائرة، اهتزاز، توقّف الضربة
│   ├── render.js       الميدان، المقاتلون، الأسلحة، الرايات
│   ├── entities.js     الوحدة (لأي الجيشين)، القائد، المقذوفات، الغنائم
│   ├── boss.js         قائد الخصم وأنماط هجومه
│   ├── ui.js           الشاشات والـHUD والغنائم
│   ├── game.js         نشرُ الجيشين والقتال والنصر والهزيمة
│   └── main.js         الإقلاع والحلقة الرئيسية
└── tools/              build-single · make-icons · test · balance · shots
```

```bash
npm install                # playwright-core للاختبار فقط
npm test                   # ١٨ اختباراً في متصفح حقيقي — منها التحرّك بلمسٍ حقيقي
npm run build              # نسخة الملف الواحد
node tools/balance.mjs     # محاكاة لاعب لقياس منحنى الصعوبة عبر المراحل
```

كل الوحدات على `window.MAL` وتُحمَّل كسكربتات عادية بالترتيب — بلا حزم ولا أدوات بناء.

## ملاحظة

المعلومات التاريخية في اللعبة مأخوذة من الروايات المشهورة في كتب التاريخ، وصيغت بحذرٍ حين تختلف الروايات.
واللعبة لا تُصوّر أشخاصاً بأعيانهم؛ أنت فيها «قائد» بلا اسم، وقادة الخصوم مذكورون بأسمائهم التاريخية.
