# أنْدَلُس — سيفٌ في الغرب

لعبة أكشن تاريخية من فوق (Top-down Roguelite) تعمل في المتصفح مباشرة — بلا تثبيت وبلا إنترنت بعد أول فتح.
تخوض بها ثمانية أقاليم أندلسية، كل إقليمٍ بأجوائه وأعدائه وزعيمه وصفحته في السجل التاريخي.

> جولةٌ واحدة تستغرق ٥–١٠ دقائق — مصمّمة لوقت الفراغ.

---

## كيف ألعب؟

| الجهاز | التحكم |
|---|---|
| **آيباد / جوال** | إصبعٌ على **يسار** الشاشة = الحركة · إصبعٌ على **يمين** الشاشة = التصويب والضرب · زرّا **الاندفاع** و**الضربة القاضية** أسفل اليمين |
| **حاسوب** | `WASD` أو الأسهم للحركة · الفأرة للتصويب (اضغط للضرب) · `مسافة` للاندفاع · `Shift` للقاضية · `Esc` للإيقاف |

- إن لم تُصوّب بنفسك، يهاجم بطلك **أقرب عدو تلقائياً** (يمكن إطفاؤه من الإعدادات).
- **نقرتان سريعتان** على جهة الحركة = اندفاع.
- الاندفاع يمنحك **مناعةً لحظية** — التوقيت الصحيح يبطئ الزمن ويملأ ضربتك القاضية.

## ماذا في اللعبة؟

- **٨ أقاليم**: جبل طارق ← قرطبة ← إشبيلية ← طليطلة ← سرقسطة ← بلنسية ← غرناطة ← البُشَرّات.
- **٨ زعماء** لكلٍّ أنماط هجومٍ خاصة وطورُ غضبٍ عند نصف الصحة.
- **٤ أبطال**: الفارس · الرامي · حامل الدرقة · العيّار — لكلٍّ سلاحه وضربته القاضية.
- **٢٦ بطاقة غنيمة** تختار واحدةً منها بعد كل موجة، فلا تتشابه جولتان.
- **دار الصَّنْعة**: ٨ تطويرات دائمة تُشترى بالذهب وتبقى معك.
- **السجل التاريخي**: ١٣ صفحة بمعلوماتٍ حقيقية عن الأندلس تُفتح كلما تقدّمت.
- **حِصارٌ لا ينتهي**: وضعٌ لانهائي مع رقمٍ قياسي محفوظ.
- موسيقى ومؤثرات **مولَّدة برمجياً** على مقامات عربية (حجاز، رست، بياتي، نهاوند، صبا، كرد) — بلا أي ملف صوتي.
- كل الرسم **متجهيٌّ إجرائي** — بلا أي صورة خارجية، فالحجم صغير والتشغيل سريع.

## التشغيل

### الأسهل: ملف واحد
افتح `dist/andalus.html` في أي متصفح. يعمل حتى بلا إنترنت.

### على الآيباد كتطبيق
1. افتح الرابط في **سفاري**.
2. زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية**.
3. سيفتح ملء الشاشة بلا شريط متصفح، ويعمل بلا إنترنت، ويحفظ تقدّمك.

### تشغيل محلي للتطوير
```bash
cd game
npx serve .          # أو أي خادم ملفات ثابت
```
> ملاحظة: `sw.js` (العمل بلا إنترنت) يحتاج `http/https`، ولا يعمل عند فتح الملف بـ `file://`.

## للمطوّر

```
game/
├── index.html              الصفحة الرئيسية
├── css/style.css           كل التنسيق (عربي RTL)
├── js/
│   ├── util.js             رياضيات، عشوائية، ألوان، أرقام عربية
│   ├── save.js             الحفظ المحلي والتقدّم الدائم
│   ├── audio.js            محرّك صوت WebAudio + موسيقى إجرائية بالمقامات
│   ├── input.js            عصوان افتراضيتان + لوحة مفاتيح
│   ├── data.js             الأقاليم، الأبطال، الأعداء، البطاقات، السجل
│   ├── fx.js               الجسيمات، الأرقام الطائرة، اهتزاز الشاشة
│   ├── render.js           رسم الساحة والشخصيات والأسلحة
│   ├── entities.js         البطل والأعداء والمقذوفات والغنائم
│   ├── boss.js             الزعماء وأنماط هجومهم
│   ├── ui.js               الشاشات والـHUD والبطاقات
│   ├── game.js             حلقة اللعب والموجات والتصادم
│   └── main.js             الإقلاع والحلقة الرئيسية
├── tools/
│   ├── build-single.mjs    يبني dist/andalus.html (ملف واحد)
│   ├── make-icons.mjs      يولّد أيقونات التطبيق من شعار اللعبة
│   ├── test.mjs            ١٨ اختباراً آلياً في متصفح حقيقي
│   ├── balance.mjs         محاكاة لاعب لقياس توازن الصعوبة
│   └── shots.mjs           لقطات للمراجعة البصرية
└── sw.js                   عامل الخدمة (العمل بلا إنترنت)
```

```bash
npm install      # playwright-core للاختبار فقط
npm test         # ١٨ اختباراً: بيانات، ساحات، بطاقات، زعماء، موجات، حفظ، أداء
npm run build    # نسخة الملف الواحد
npm run icons    # إعادة توليد الأيقونات
node tools/balance.mjs   # قياس منحنى الصعوبة
```

كل الوحدات تُسجَّل على `window.MAL` وتُحمَّل كسكربتات عادية بالترتيب — بلا حزم ولا أدوات بناء.

## ملاحظة تاريخية

الخصوم في اللعبة **قُطّاع طرقٍ ومرتزقةٌ وأمراءُ متمردون** — وهي وقائع حقيقية من تاريخ الأندلس الداخلي.
والمعلومات في «السجل» مأخوذة من وقائع مشهورة، وصيغت بحذرٍ حين تكون الرواية محلَّ خلافٍ بين المؤرخين.
